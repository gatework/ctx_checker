# 配置到报告的性能验证（2026-10-21）

`benchmark/pipeline.rb` 使用合成 IOS 配置与接口回显，贯通配置适用性、借用会话采集、共享命令解析、观测快照和策略报告。输入与策略构造不计时，每个阶段执行三次，报告按耗时取中位数的样本及其对象分配量。计时后断言接口数、计数记录数、共享查询次数、健康结论及配置证明的 BGP 不适用状态。

在 macOS arm64、Ruby 4.0.6 上，先定位 `Observation#validate_record` 为每个字段创建的临时键值数组，再定位 `CtxParser::Immutable.copy` 两条 Hash 复制路径创建的键值数组。修改为直接填充新 Hash，保留字段顺序、缺失值、键和值的求值顺序、深冻结、共享引用和循环拒绝契约。没有复用调用方的可变容器。

以下比较只隔离这两处对象分配优化；两组均包含本轮输入归一化和回调快照修复。基线采用独立临时库副本，仅将 `observation.rb`、`immutable.rb` 替换为各自起始提交 `9ef2811`、`b8746d9` 的版本。交替运行两次基线进程与两次候选进程，每个进程内部各阶段三次取中位数；区间是两个进程的结果范围，不是统计置信区间。

| 接口数 / 阶段 | 优化前分配 | 优化后分配 | 优化前耗时 ms | 优化后耗时 ms |
| --- | ---: | ---: | ---: | ---: |
| 1000 / 采集解析 | 574486 | 358460–358461 | 79.679–80.916 | 76.261–76.829 |
| 1000 / 评估报告 | 101475 | 63365 | 16.934–17.163 | 16.567–16.726 |
| 5000 / 采集解析 | 2866485 | 1786460 | 411.596–422.541 | 406.206–412.796 |
| 5000 / 评估报告 | 505475 | 315365 | 86.099–86.119 | 83.890–86.420 |

5000 接口的配置为 293912 字节，回显为 463893 字节。采集解析对象分配减少约 37.7%，评估报告减少约 37.6%。配置阶段没有实质变化（约 39 ms）；耗时改善较小，评估区间重叠，不能宣称稳定的端到端加速比例。对象分配数不等于内存峰值，也不能外推为真实设备或网络吞吐收益。

复测当前候选：

```sh
RUBYLIB=../ctx_parser/lib:../ctx_driver/lib bundle exec ruby -Ilib benchmark/pipeline.rb
```

脚本打印五个关键入口的实际源码路径。比较旧版本时，在临时目录复制库并替换目标文件，通过 `RUBYLIB` 与 `-I` 指向对应副本，不覆盖工作区。比较时保持输入、Ruby、依赖及其他源码一致。该脚本属于仓库开发工具，不包含在运行 gem 中。
